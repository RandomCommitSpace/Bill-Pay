## 🇺🇸 English Version

### 📝 About the Project
This is a **University Project** designed as a proof-of-concept for a bill management system. It serves as the **First Version (v0.1)** and is intended for testing purposes. The app allows users to view their bills (Electricity, Water, Gas, etc.), simulate payments, and track their history.

> [!IMPORTANT]
> This is an educational project. Real payment gateways are NOT implemented; instead, a simulated "Fake Payment" interface is used.

### 🚀 Key Features
- 🔐 **Dual Login**: Sign in using Phone Number or Email.
- 📊 **Bill Dashboard**: View all unpaid bills with details.
- 💳 **Payment Simulator**: A mock bank gateway for testing transactions.
- 📜 **History**: Full log of successful and failed payments.
- 👤 **Profile Stats**: Summary of total paid amounts and bill counts.

### 🔑 Test Access (Credentials)
Since this is a closed test version, access is limited to pre-seeded users in the database:

| Type | Examples |
| :--- | :--- |
| **Allowed Phones** | `09100000001` to `09100000020` |
| **Allowed Emails** | `user1@gmail.com` to `user20@gmail.com` |
| **Blocked Access** | `09900000001`, `blocked1@gmail.com` |

### 🛠 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/RandomCommitSpace/BillPayment.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle and run on an Emulator or Physical Device (API 24+).
